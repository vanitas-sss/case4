# UI Guide · MOTY Console

Руководство по интерфейсу для вёрстки. Источник правды: макеты в Figma (кадры Review, Servers, Containers, Metrics, Magazine, Sources, Documentation и их состояния).

- Холст макетов: **1360 × 820 px**, только десктоп. Мобильная версия не рисовалась, значения для неё в документе не придуманы.
- Тема: тёмная, **плоская заливка**. Градиентов, теней и свечения в системе нет.
- Бренд в сайдбаре: `MOTY` + подпись `INFRASTRUCTURE CONSOLE`.

---

## 1. Принципы

1. **Цвет означает статус.** Интерфейс монохромный (графит и «кость»). Цветными бывают только статусы: зелёный, жёлтый, красный.
2. **Статус никогда не передаётся одним цветом.** Рядом всегда круг и текстовая подпись.
3. **Числа и метки набираются моноширинным шрифтом**, текст интерфейса вторым шрифтом.
4. **Один способ сделать одно.** Одна кнопка основного действия на экране, один набор радиусов, одна сетка.
5. **Каждый экран имеет все состояния** (раздел 8), а не только «норму».

## 2. Токены

### 2.1. Цвета

| Токен | HEX | Где используется |
|---|---|---|
| `--bg` | `#0F0F0E` | фон страницы |
| `--bg-side` | `#0B0B0A` | сайдбар, фон полей ввода |
| `--surface` | `#171716` | карточки |
| `--surface-2` | `#1E1E1C` | активный пункт меню |
| `--border` | `#2A2A27` | рамки, разделители |
| `--text` | `#ECE8DC` | основной текст, основная кнопка |
| `--text-2` | `#9A968A` | вторичный текст |
| `--text-3` | `#6B685F` | третичный текст, подписи колонок |
| `--ok` | `#9ED36A` | в норме |
| `--warn` | `#E8B04A` | внимание |
| `--crit` | `#F0584B` | критично |

Производные (считаются от токенов, отдельных цветов не вводить):

| Назначение | Правило |
|---|---|
| Плашка статуса | заливка статусного цвета 12 %, рамка 30 % |
| Подсветка строки таблицы (внимание, критично) | статусный цвет 6 % |
| Трек полоски нагрузки | `--text` 9 % |
| Скелетон | `--text` 7 %, заголовок блока 12 % |
| Баннер | заливка статусного цвета 12 %, рамка 45 % |
| Недоступное содержимое (Offline) | `opacity: .45` на всём блоке контента |

### 2.2. Типографика

Шрифты: **IBM Plex Sans** (400, 500, 600) и **IBM Plex Mono** (400, 500, 600). Оба есть в Google Fonts.

| Роль | Шрифт | Размер / вес | Цвет |
|---|---|---|---|
| Заголовок страницы (H1) | Sans | 26 / 600, `letter-spacing: -0.4px` | `--text` |
| Заголовок карточки (H2) | Sans | 16 / 600 | `--text` |
| Основной текст | Sans | 14 / 400 | `--text` |
| Имя в строке таблицы | Sans | 14 / 600 | `--text` |
| Вторичный текст | Sans | 13 / 400 | `--text-2` |
| Подпись карточки | Sans | 12 / 400 | `--text-2` |
| KPI-цифра | Mono | 40 / 500, `letter-spacing: -1px` | `--text` |
| Значение в сводке | Mono | 30 / 500, `letter-spacing: -0.6px` | `--text` или `--crit` |
| Данные (время, IP, проценты) | Mono | 12.5 / 400–500 | `--text` или `--text-2` |
| Метка колонки / блока | Mono | 11 / 500, uppercase, `letter-spacing: .8px` | `--text-3` |

Минимальный размер текста в системе: **11 px**. Цифры в таблицах и KPI: `font-variant-numeric: tabular-nums`.

### 2.3. Отступы, радиусы, размеры

- Шкала отступов (сетка 8 px): `4, 8, 12, 16, 24, 32, 48`.
- Радиусы: **6** (малые кнопки), **8** (кнопки, поля, баннеры-плашки), **12** (карточки), плашки статуса и пилюли: полный радиус (`999px`).
- Рамка: **1 px**, цвет `--border`.
- Высоты: кнопка **38**, малая кнопка **30**, поле и поиск **36**, плашка статуса **24**, строка таблицы **62**, KPI-блок **124**.

## 3. Раскладка страницы

```
┌──────────┬─────────────────────────────────────────────────┐
│ Sidebar  │ Header: H1 + подзаголовок            [LIVE]     │
│ 232 px   ├─────────────────────────────────────────────────┤
│          │ Content: ширина 1064 px, поля по 32 px          │
└──────────┴─────────────────────────────────────────────────┘
```

- Сайдбар: ширина **232**, фон `--bg-side`, справа рамка 1 px.
- Контент начинается на **264 px** от левого края (232 + 32), заканчивается на **1328 px** (правый отступ 32). Ширина контента **1064**.
- Заголовок страницы и подзаголовок в шапке слева, индикатор справа (раздел 5.9). Правый край индикатора: x = 1292. Колокольчик (раздел 5.13), если он есть, стоит на x = 1292–1328, индикатор тогда сдвигается на 12 px влево (правый край 1280).
- Расстояние между блоками контента: **16 px**. Внутренний отступ карточки: **24 px**.
- Заголовок карточки: базовая линия на 36 px от верха карточки, подпись под ним на 57 px.

## 4. Статусы

Статус = круг 9 px + подпись. Круг ставится слева от подписи, расстояние 8 px.

| Статус | Цвет круга | Где встречается (подписи в макетах) |
|---|---|---|
| В норме | `--ok` | В сети, Running, Работает, Подключён |
| Внимание | `--warn` | Нагрузка, Restarting, Внимание, В работе |
| Критично | `--crit` | Нет связи, Exited, Ошибка, Критично |
| Инфо | `--text` | Инфо, Новое |
| Закрыто | `--text-3` | Закрыто |

**Пороги нагрузки (CPU, RAM, диск):**

| Значение | Цвет полоски и числа |
|---|---|
| до 74 % | `--text` (полоска с прозрачностью 85 %) |
| 75–89 % | `--warn` |
| 90 % и выше | `--crit` |

## 5. Компоненты

### 5.1. Кнопки

| Вид | Заливка | Рамка | Текст | Высота |
|---|---|---|---|---|
| Основная | `--text` | нет | `--bg`, 13 / 600 | 38 |
| Вторичная | нет | `--border` | `--text`, 13 / 600 | 38 |
| Опасная | нет | `--crit` | `--crit`, 13 / 600 | 38 |
| Малая основная | `--text` | нет | `--bg`, 12 / 600 | 30 |
| Малая вторичная | нет | `--border` | `--text`, 12 / 600 | 30 |
| Загрузка | `--text` 55 % | нет | `--bg`, спиннер слева | 38 |
| Недоступна | нет | `--border` | `--text-3` | 38 |

Радиус 8 (малые 6). Горизонтальный отступ внутри кнопки 24 px. На экране одна основная кнопка. Опасная используется только в диалоге подтверждения разрушительного действия.

### 5.2. Поля ввода

Высота 36, радиус 8, фон `--bg-side`, рамка 1 px, текст 13 / 400, отступ слева 14 px.

| Состояние | Что меняется |
|---|---|
| Default | рамка `--border`, плейсхолдер `--text-3` |
| Focus | рамка `--text` |
| Error | рамка `--crit`, под полем красный круг и текст ошибки (Mono 12 / 500, `--crit`) |
| Disabled | `opacity: .45` |

Над полем метка: Mono 11 uppercase `--text-3`. Выпадающий список: то же поле со стрелкой `⌄` справа. Поиск: поле с иконкой лупы слева.

Текст ошибки говорит, что исправить: «Введите IP в формате 10.0.1.50», а не «Неверное значение».

### 5.3. Плашка статуса (chip)

Высота 24, полный радиус. Круг 9 px слева (отступ 14 px от края), подпись 11.5 / 500 справа от круга. Заливка и рамка по правилу из 2.1. Цвет подписи: статусный. Для «Инфо» и «Закрыто» подпись `--text`, плашка нейтральная.

### 5.4. Вкладки и фильтры

- Вкладки: текст 13, активная 600 `--text` с подчёркиванием 2 px, остальные 500 `--text-2`. Расстояние между вкладками 28 px (в шапке карточки 20 px).
- Фильтры над таблицей: поля-списки высотой 36.
- Переключатель периода (1ч, 6ч, 24ч) прижат к правому краю карточки графика на одной линии с её заголовком.

### 5.5. Карточка

Заливка `--surface`, рамка 1 px `--border`, радиус 12, внутренний отступ 24. Заголовок 16 / 600, подпись 12 `--text-2`. Скроллить содержимое внутри карточки не нужно: таблицы вмещаются на экране макета.

### 5.6. KPI-блок (strip)

Одна карточка высотой **124** с четырьмя равными ячейками, между ячейками вертикальный разделитель 1 px. В ячейке сверху вниз: метка (Mono 11 uppercase), число (Mono 40 / 500), строка пояснения (круг статуса + текст 12 `--text-2`). Единицы измерения («%», «/ 20») Mono 14 `--text-3` рядом с числом. Блок всегда из 4 ячеек.

### 5.7. Таблица

- Заголовки колонок: Mono 11 uppercase `--text-3`, под ними линия 1 px.
- Строка высотой **62**, разделитель 1 px между строками, центр содержимого по вертикали по центру строки.
- Первая колонка: круг статуса (9 px), затем имя (14 / 600). Центр круга на 28.5 px от левого края карточки, имя начинается на 44 px от края карточки.
- Проценты у полосок выравниваются по правому краю.
- Строки со статусом «внимание» и «критично» подсвечены заливкой 6 % статусного цвета с отступом 8 px от краёв и радиусом 8.
- В журнале событий у критичной строки слева полоска `--crit` шириной 3 px.

Сетка колонок (от левого края контента карточки, ширина контента 1016 px):

| Таблица | `grid-template-columns` |
|---|---|
| Servers | `182px 130px 160px 160px 160px 90px 1fr` (узел, IP, CPU, RAM, диск, аптайм, статус) |
| Containers | `182px 170px 180px 170px 160px 1fr` (контейнер, образ, хост, CPU, память, статус) |
| Magazine | `112px 140px 160px 450px 1fr` (время, уровень, источник, описание, статус) |
| Review, «Последние события» | `112px 180px 570px 1fr` (время, источник, событие, уровень) |

Полоска нагрузки: длина 70 px, высота 6, радиус 3, справа значение в процентах.

### 5.8. График

- Линия CPU: `--text`, 2.2 px. Линия RAM: `--text-2`, 1.6 px, пунктир `2 4`.
- Заливка под линией CPU: `--text` 6 %.
- Сетка: горизонтальные линии `--border`, подписи по оси Y (0, 25, 50, 75, 100) Mono 11 `--text-3`.
- Порог: линия `--crit`, пунктир `6 5`, подпись «порог 85 %» справа над линией.
- Пик выше порога: квадрат 10 px `--crit` и подпись значения и времени (Mono 12 / 600, `--crit`).
- Подсказка: блок `--text` с текстом `--bg`, Mono 12 / 500.

### 5.9. Сайдбар и шапка

- Пункт меню: высота 40, радиус 8, иконка 24 px (линия 1.8 px) и текст 14. Активный: заливка `--surface-2`, полоска слева 3 px `--text`, текст 600 `--text`. Неактивный: `--text-2`.
- Счётчики у пунктов («Серверы», «События»): круг статуса и число (Mono 12 / 500), прижаты вправо.
- Группы меню: «Мониторинг» (5 пунктов), «Система» (2 пункта), подпись группы Mono 11 uppercase.
- Блок пользователя прижат к низу сайдбара: карточка 200 × 64, аватар 32 px, имя 13 / 600, почта Mono 11.
- Индикатор в шапке справа: пилюля высотой 36 с рамкой, правый край на **x = 1292**. `LIVE` + время (зелёный круг): ширина **164** (x 1128–1292). Внутри: круг по центру на 22 px от левого края, текст `LIVE` на 36 px, время на 80 px. Другие варианты сужаются по тексту и прижаты к тому же правому краю: `ОБНОВЛЕНИЕ…` (серый круг, ширина 148), `НЕТ ДАННЫХ` (красный круг, ширина 140). Для Offline и Partial вместо пилюли баннер (раздел 8).

### 5.10. Диалог подтверждения

Фон `--bg`, рамка `--text` 50 %, радиус 12. Заголовок 20 / 600, пояснение 13 `--text-2` в 2 строки, кнопки справа внизу: вторичная «Отмена» и опасная. Заголовок называет действие и объект: «Остановить api-gateway?». Пояснение говорит о последствии и о том, можно ли отменить.

### 5.11. Уведомление (toast)

Панель на заливке `--surface-2` с рамкой `--text` 25 %, текст `--text` 13 / 500, круг статуса слева, крестик справа. Радиус 10, размер 400 × 56. Стек растёт вверх от левого нижнего угла контента, расстояние между тостами 12 px. Действие («Повторить», «Отмена») 13 / 600 справа от текста. Внизу линия 2 px показывает оставшееся время (`--text` 50 %). Заливка кремовым цветом не используется: цветные круги на нём теряют контраст.

### 5.12. Иконки

24 px, линия 1.8 px, `stroke-linecap: round`, `stroke-linejoin: round`, без заливки. Набор: Обзор, Серверы, Контейнеры, Метрики, События, Источники, Документация, Плюс, Закрыть, Готово, Поиск, Уведомления, Стрелка, Список. Цвет иконки в меню совпадает с цветом текста пункта.

### 5.13. Уведомления (колокольчик)

- Кнопка 36 × 36, радиус 8, рамка `--border`, на x = 1292–1328 справа от индикатора `LIVE` (индикатор сдвигается на 12 px влево, правый край 1280). Бейдж: красный круг 18 px с числом (Mono 11 / 600, цвет `--bg`) в правом верхнем углу кнопки. При открытой панели рамка кнопки `--text`, заливка `--surface-2`.
- Панель 440 px по ширине, радиус 12, заливка `--surface-2`, рамка `--text` 25 %, прижата правым краем к кнопке на 12 px ниже шапки. Остальная страница под панелью затемнена (`--bg` 50 %), шапка не затемняется.
- Внутри: заголовок и ссылка «Прочитать все», вкладки («Все», «Критичные N»), список, подвал со ссылками «Все события →» и «Настроить оповещения →».
- Строка уведомления 72 px: круг статуса, заголовок 13.5, пояснение 12 `--text-2`, время справа (Mono 11 `--text-3`). Непрочитанная строка: заливка `--text` 5 % и заголовок 600, прочитанная: заголовок 500 `--text-2`.
- Пустое состояние: иконка колокольчика в пунктирном круге, «Новых уведомлений нет» и пояснение в две строки.

### 5.14. Выпадающие списки (прикреплённые плашки)

- Открытое поле: рамка `--text`, стрелка меняется на `⌃`. Панель появляется под полем с зазором 4 px, ширина равна полю (для списков с поиском допустимо шире), радиус 8, заливка `--surface-2`, рамка `--text` 25 %.
- Пункт 36 px, радиус 6, текст 13. Выбранный: заливка `--text` 8 %, текст 600 `--text`, галочка справа. Остальные: `--text-2`.
- В списке узлов сверху поле «Найти узел», у каждого узла круг статуса, внизу счётчик «Показано 6 из 20» и полоса прокрутки. Список периодов заканчивается пунктом «Свой период…».
- Закрытие: клик вне панели, Esc, выбор пункта.
- Фильтры журнала (Magazine): «Уровень» (Все, Критично, Внимание, Инфо), «Статус» (Все, Новое, В работе, Закрыто), «Период» (час, 24 часа, 7 дней, 30 дней, «Свой период…»). У пунктов уровня и статуса слева круг статуса.
- Меню статуса события: открывается под плашкой статуса в таблице, ширина 180, заголовок «Статус события» (Mono 11), три пункта (Новое, В работе, Закрыто), текущий отмечен галочкой. Плашка при открытом меню обведена `--text` 60 %.

### 5.15. Поиск

- По фокусу поле раскрывается с 200 до 360 px влево, рамка `--text`. Под полем панель 360 px.
- Пустой запрос: «Недавние» (до 3, с крестиком у каждого) и «Быстрые фильтры» (плашки статусов), внизу подсказка клавиш Mono 11: «↑↓ выбор · Enter открыть · Esc закрыть».
- Есть запрос: слева в поле лупа, справа кнопка очистки. Результаты по группам: «Узлы · N» и «События · N». Совпадающая часть имени подсвечена заливкой `--text` 16 %. Первая строка выбрана (заливка 8 %, справа значок `↵`).
- Нет результатов: иконка, «Ничего не найдено», пояснение с запросом в кавычках, подсказка про область поиска, кнопка «Сбросить поиск».
- Остальная страница затемнена на `--bg` 55 %.
- Совпадение с запросом выделяется **жирным `--text`**, несовпавшая часть строки `--text-2`. Заливкой выделение не делается: так оно не зависит от ширины шрифта.
- Журнал (Magazine): поле раскрывается влево до 400 px, в панели группа «События» и ссылка «Искать «запрос» среди узлов →».
- Документация: поиск фильтрует список статей на месте. Карточка называется «Результаты поиска» с подписью «Найдено: N · запрос «…»», в названиях статей совпадение выделено жирным.

### 5.16. Панель узла (клик по строке)

- Правая панель 480 px на всю высоту, заливка `--surface`, слева рамка `--text` 25 %. Страница под ней затемнена `--bg` 60 %, выбранная строка таблицы обведена `--text` 35 %.
- Шапка: имя узла 24 / 600, строка «IP · система» Mono 12, плашка статуса, кнопка закрытия 36 × 36. Вкладки: «Обзор», «Параметры», «События N».
- «Обзор»: блок «Сейчас» (CPU, RAM, диск: значение Mono 26 / 500 в цвете порога и полоска 128 px), график за 1 час с порогом, список параметров (группа, теги, экспортер, последний сигнал, аптайм, порт метрик).
- Подвал с линией сверху: основная «Открыть метрики», вторичная «Перезапустить», справа текстовая красная «Удалить».
- Узел без связи: красный баннер внутри панели («Нет ответа 14 мин · последний сигнал …»), значения «—», вместо графика блок «Нет данных», основное действие «Повторить проверку».
- «Перезапустить»: диалог подтверждения по центру экрана (раздел 5.10), основная кнопка «Перезапустить», страница и панель затемнены.

### 5.17. Логотип

- Знак: квадрат 36 × 36 со скруглением 10 (28 % стороны), заливка `#ECE8DC`. Внутри два пика-«шеврона» цвета `#0B0F14`. Координаты в сетке 36 × 36:
  - правый пик: `24,12  30,23.5  24,20  18,23.5`
  - левый пик: `12,12  18,23.5  12,20  6,23.5`
- Цвет пиков `#0B0F14` взят из исходного файла логотипа и чуть синее `--bg`. Это сознательное исключение, отдельный токен не нужен.
- Версия для светлого фона: цвета меняются местами (квадрат `#0B0F14`, пики `#ECE8DC`).
- В сайдбаре знак 36 px, рядом `MOTY` (Plex Sans 700, `letter-spacing` 1px) и подпись `INFRASTRUCTURE CONSOLE` (Mono 10.5 / 500, `--text-3`).
- Минимальный размер знака 16 px, охранное поле 1/6 стороны. Знак плоский, без градиента и тени, не вращать и не растягивать.
- Исходник логотипа: файл `kkk.svg` (36 × 36), его и использовать в вёрстке.

### 5.18. Диалоги

Общие правила: затемнение всего экрана `--bg` 60 %, диалог по центру, рамка `--text` 25 %, радиус 12, внутренний отступ 32. Заголовок 22 / 600, пояснение 13 `--text-2`. Кнопки справа внизу: «Отмена» (вторичная) слева, действие справа. Расстояние от нижнего края до кнопок 32.

## 7. Тексты

- Язык интерфейса: русский. Технические названия (Prometheus, Running, Restarting, Exited) не переводить.
- Кнопка называет действие: «Добавить сервер», «Повторить», «Остановить», а не «ОК».
- Заголовок пустого состояния говорит, чего нет («Узлов пока нет»), пояснение говорит, что делать.
- Ошибка называет, что случилось, что с данными пользователя и что делать дальше.
- Время в формате `ЧЧ:ММ:СС`, периоды «1ч / 6ч / 24ч», большие числа с пробелом, дробные с запятой («99,98 %», «92,1 %»).

## 8. Состояния страниц

Каждый кадр существует в 6 состояниях: **Default, Loading, Empty, Error, Offline, Partial**. Имя кадра в Figma: `<Страница> - <Состояние>`, например `Servers - Error`.

| Состояние | Что показывать |
|---|---|
| **Default** | обычный экран |
| **Loading** | каркас страницы из серых блоков по реальной раскладке. Над контентом полоска прогресса 2 px (30 % длины `--text`, бежит слева направо). В шапке пилюля `ОБНОВЛЕНИЕ…`. Цифры и таблицы не показывать |
| **Empty** | в центре карточки иконка раздела (увеличена вдвое) в пунктирном круге радиусом 44, заголовок 22 / 600, пояснение 14 `--text-2`, одна кнопка. Панели фильтров остаются |
| **Error** | в центре карточки код ошибки (Mono 96 / 500, `--crit`), название ошибки, заголовок 28 / 600, пояснение, строки «Запрос / Время / ID запроса», кнопки «Повторить», «Копировать детали», «На обзор» |

Коды ошибок по страницам: Review 502, Servers 504, Containers 503, Metrics 500, Magazine 504, Sources 502, Documentation 500.

Системные страницы: крупный код контурным начертанием (без заливки, обводка 1.5 px `--text`), название, пояснение, строки «Запрос» и кнопки.

## 9. Доступность

Контраст рассчитан по формуле WCAG:

| Пара | Контраст | Оценка |
|---|---|---|
| `--text` на `--bg` | 15.7 : 1 | отлично |
| `--text` на `--surface` | 14.6 : 1 | отлично |
| `--text-2` на `--surface` | 6.1 : 1 | проходит AA |
| `--ok` на `--surface` | 10.2 : 1 | проходит |
| `--warn` на `--surface` | 9.2 : 1 | проходит |
| `--crit` на `--surface` | 5.3 : 1 | проходит AA |
| `--text-3` на `--surface` | **3.2 : 1** | **не проходит AA для мелкого текста** |

Что с этим делать:

- `--text-3` в макетах используется для подписей колонок, меток и пояснений. Нельзя использовать его для информации, без которой пользователь не справится. Если нужен проходной контраст, заменить на `#8A867B` (4.9 : 1 на `--surface`).
- Статус передаётся кругом и подписью, а не только цветом.
- Размер текста от 11 px. Интерактивные элементы не ниже 30 px по высоте.
- Для фокуса с клавиатуры нужна видимая обводка (раздел 10).

## 10. Чего нет в макетах (решает разработка, согласовать с дизайнером)

В Figma нарисованы статичные кадры. Ниже рекомендации, а не утверждённые значения:

- Hover строки таблицы: фон `--surface-2`.
- Фокус с клавиатуры: `outline: 2px solid var(--text); outline-offset: 3px`.
- Disabled: `opacity: .45`, курсор `not-allowed`.
- Анимация скелетона: пульсация прозрачности 1.2 с. Для `prefers-reduced-motion` отключить.
- Переходы: до 150 мс, только для цвета и прозрачности.
- Мобильные и планшетные раскладки, тёмная и светлая темы переключателем: не рисовались.

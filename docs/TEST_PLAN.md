# Проверки

## Автоматические

```bash
cd backend && python -m pytest
cd frontend && npm ci && npm run lint && npm run format:check && npm test && npm run build
```

Интеграционные тесты Playwright запускаются через GitHub Actions.

## Перед защитой

- [ ] Пустая база не показывает выдуманные измерения.
- [ ] Импорт JSON принимает корректные отчёты и описывает ошибки.
- [ ] Серверы, контейнеры, метрики и топология отображаются.
- [ ] После 10/20/30 секунд тишины меняются статусы и возникает тревога.
- [ ] Повторный heartbeat не создаёт дублей; восстановление закрывает тревогу.
- [ ] События и оповещения работают внутри сайта без Telegram.
- [ ] История сохраняется после перезапуска backend.
- [ ] Интерфейс корректен на узком и широком экране.

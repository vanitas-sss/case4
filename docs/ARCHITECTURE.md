# Архитектура

`mock-data` или внешний источник → `POST /api/v1/ingest` → FastAPI → SQLite → `GET /api/v1/*` → React.

```text
backend/app/
  api/v1/        HTTP-маршруты
  schemas/       Проверка входного JSON
  services/      Обработка отчётов, алерты, сводные данные
  repositories/  Запись и чтение данных
  models/        Таблицы SQLAlchemy
  workers/       Heartbeat и очистка истории
  db/            Сессия SQLite и миграции
frontend/src/
  api/           Запросы и React Query
  app/           Маршруты и общий макет
  components/    Общие компоненты
  features/      Страницы
mock-data/       Генератор без доступа к оборудованию
contracts/       Примеры входного и выходного JSON
```

SQLite хранит текущее состояние, историю метрик, проверки доступности, события и алерты. Идентификатор сервера — пара `source_id + host.name`; контейнера — `host_id + docker_id`.

Время последнего сигнала берётся при получении отчёта. `warning` через 10 с, `offline` через 20 с, тревога через 30 с при стандартных настройках. После восстановления тревога закрывается автоматически.

Ограничения: без реального агента, управления инфраструктурой и авторизации пользователей. Формат кейса №1 пока не согласован.

# Согласование с кейсом №1

Статус: **ожидаем реальный JSON-отчёт команды кейса №1**. Подтверждённого контракта или готового адаптера пока нет.

Наш формат: [api-examples.json](api-examples.json). Поддерживаются массив отчётов через `POST /api/v1/ingest` и загрузка такого же JSON через `POST /api/v1/import`.

После получения образца нужно проверить: `source_id`, время сбора, сервер, контейнеры, сети, связи и статусы. Только затем реализовать и протестировать преобразование. Никакие договорённости с другой командой здесь не выдумываются.

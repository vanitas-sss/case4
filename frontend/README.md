# Frontend

React + Vite. Работающие страницы: обзор, серверы, контейнеры, метрики, топология, события, оповещения, источники, справка.

```bash
npm ci
npm run dev
```

Vite: http://localhost:5173 (backend запускается отдельно на 8000).

```bash
npm run lint
npm run format:check
npm test
npm run build
```

Правила оформления: [UI Guide](../docs/UI_GUIDE1.md).

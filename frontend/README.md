# Интерфейс мониторинга

React, Vite, TanStack Query и Recharts. Все данные запрашиваются у backend; автоматической подмены моками нет.

## Разработка

Запустите backend на `127.0.0.1:8000`, затем из этой папки:

```sh
npm ci
npm run dev
```

Интерфейс: http://localhost:5173. Vite проксирует `/api` на backend. Для работы страниц нужен источник данных или импорт JSON.

## Проверки

```sh
npm run lint
npm run format:check
npm test
npm run build
```

`npm run format` форматирует код. `npm run test:e2e` проверяет работающий Docker-стенд на порту 8080 с чистой тестовой базой; подготовка описана в [инструкции Docker](../docs/DOCKER_GUIDE_RU.md).

## Структура

- `src/api` — HTTP-запросы и автоматическое обновление.
- `src/app` — маршруты, общий layout и кэш запросов.
- `src/components` — общие компоненты и состояния запросов.
- `src/features` — страницы мониторинга, топологии и импорта.
- `src/utils` — форматирование и расчёты без подмены отсутствующих значений нулями.
- `tests` — проверки чистых функций.
- `e2e` — браузерные сценарии с настоящим API.

Docker использует сборку Vite и nginx, а не сервер разработки. Конфигурация nginx поддерживает переход по прямым адресам страниц и проксирование API.
